# Exploratory Charters — module_admin_job

1. **Delete all dependencies:** Thử xóa Pay Grade, Job Category, Employment Status khi chúng đang được gán cho nhiều Employee. Xác nhận xem có cảnh báo hay chặn lại (soft warn vs hard block).
2. **File upload (Job Specification):** Thử upload file cực lớn hoặc định dạng lạ (`.sh`, `.exe`) vào Job Spec xem server có bắt không.
3. **Empty states:** Xóa sạch tất cả Job Titles, rồi qua PIM xem form thêm Employee hoạt động thế nào.
